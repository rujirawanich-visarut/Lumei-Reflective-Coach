# สื่อสารความเห็นต่างและหาข้อตกลง

Work through disagreement · `GWS-work-through-disagreement` · release candidate 0.2.0 · runtime_authority: false

## ใช้เมื่อ

มีความเห็นต่างที่คุยได้อย่างปลอดภัยและต้องกำหนดสิ่งที่จะทำต่อร่วมกัน

## พฤติกรรมและหลักฐาน

- **A1** อธิบายประเด็นและผลกระทบที่สังเกตได้ โดยไม่กล่าวหาบุคลิกหรือแรงจูงใจ (H-22)
- **A2** ฟังความต้องการและข้อจำกัดของอีกฝ่าย แล้วตรวจว่าตนเข้าใจตรงกับเขาหรือไม่ (H-22, H-11)
- **A3** เสนอทางเลือกที่ตอบประเด็น และสรุปสิ่งที่ตกลง/ยังไม่ตกลงพร้อมการกระทำถัดไป (H-22, H-23)

หลักฐานที่มองหา: คำพูดหรือประเด็นที่คุยจริง / ความต้องการที่อีกฝ่ายยืนยัน / ข้อตกลง/ข้อที่ยังค้างและผู้ทำต่อ

## ขอบเขตและข้อจำกัด

- ใช้เฉพาะงานและข้อมูลที่ผู้ใช้มีสิทธิ
- ไม่แทนขั้นตอนองค์กรหรือความรู้เฉพาะวิชาชีพ
- เหตุการณ์คุกคาม ความปลอดภัยหรือความเสี่ยงสูงต้องใช้ช่องทางที่เหมาะสมก่อนกิจกรรมฝึก
- ไม่ชวนเผชิญหน้าหรือไกล่เกลี่ยในเหตุการณ์คุกคาม ล่วงละเมิด หรืออำนาจไม่สมดุลจนไม่ปลอดภัย
- ฟังแล้วไม่เท่ากับเห็นด้วย
- การสนทนาครั้งเดียวไม่พิสูจน์ว่าความขัดแย้งยุติหรืออีกฝ่ายเปลี่ยนใจ
- ข้อเสนอการฝึกไม่ใช่หลักฐานว่าผู้ใช้เคยทำหรือทำได้แล้ว
- ไม่ให้คะแนน ระดับ proficiency หรือคำตัดสินตัวตนจากเหตุการณ์

## กิจกรรมฝึกที่เลือกได้

ร่างข้อความเปิดการคุยสั้น ๆ จากข้อเท็จจริงหนึ่งอย่าง ผลกระทบ และคำเชิญให้อีกฝ่ายอธิบาย

**Feedback:** ข้อความระบุประเด็นโดยไม่โจมตีหรือไม่; เปิดพื้นที่ให้ตอบและปฏิเสธได้หรือไม่

**ลองต่างบริบท:** เปลี่ยนจากต่างกันเรื่องเวลาเป็นต่างกันเรื่องคุณภาพ ระบุว่าความต้องการและขอบเขตการคุยต่างอย่างไร

**หลักฐานถัดไป:** คำพูดหรือประเด็นที่คุยจริง / ข้อตกลง/ข้อที่ยังค้างและผู้ทำต่อ

**ขอบเขต AI:** AI ช่วยจัดโครงหรือชี้ข้อมูลที่ยังขาดได้ ผู้ใช้เป็นเจ้าของเหตุผลและปฏิเสธกิจกรรมได้; ไม่ grading

**หยุดเมื่อ:** ผู้ใช้ไม่ต้องการฝึก / งานเกินสิทธิหรือเสี่ยงกระทบคน/ระบบจริง / ต้องมีผู้รับผิดชอบเฉพาะทางแต่ยังไม่พร้อม

## ความต่างจาก card ใกล้เคียง
