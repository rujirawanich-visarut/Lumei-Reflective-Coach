# ทำความเข้าใจงานและความคาดหวัง

Clarify work and expectations · `GWS-clarify-work` · release candidate 0.2.0 · runtime_authority: false

## ใช้เมื่อ

ได้รับคำขอที่เป้าหมาย ผลส่งมอบ หรือข้อจำกัดยังไม่ชัด

## พฤติกรรมและหลักฐาน

- **A1** ระบุส่วนที่เข้าใจและส่วนที่ยังต้องยืนยัน แยกคำขอออกจากข้อสันนิษฐานของตน (H-14)
- **A2** ถามผู้เกี่ยวข้องเรื่องผลที่ต้องการ ผู้ใช้ผลงาน และข้อจำกัดที่มีผลต่อการทำงาน (H-11, H-26)
- **A3** สรุปความเข้าใจกลับ พร้อมจุดที่ยังเปิดอยู่ และขอการยืนยันก่อนยึดเป็นข้อตกลง (H-11)

หลักฐานที่มองหา: คำถามที่ผู้ใช้ถามจริง / คำตอบหรือข้อกำหนดที่ได้รับ / ข้อความสรุปและสถานะการยืนยัน

## ขอบเขตและข้อจำกัด

- ใช้เฉพาะงานและข้อมูลที่ผู้ใช้มีสิทธิ
- ไม่แทนขั้นตอนองค์กรหรือความรู้เฉพาะวิชาชีพ
- เหตุการณ์คุกคาม ความปลอดภัยหรือความเสี่ยงสูงต้องใช้ช่องทางที่เหมาะสมก่อนกิจกรรมฝึก
- การถามหนึ่งครั้งไม่พิสูจน์ว่าทั้งทีมเข้าใจตรงกัน
- ยังไม่ได้รับคำตอบต้องคงสถานะความคาดหวังที่ยังไม่ยืนยัน
- ข้อเสนอการฝึกไม่ใช่หลักฐานว่าผู้ใช้เคยทำหรือทำได้แล้ว
- ไม่ให้คะแนน ระดับ proficiency หรือคำตัดสินตัวตนจากเหตุการณ์

## กิจกรรมฝึกที่เลือกได้

เขียนสรุปคำขอหนึ่งประโยค แล้วเลือกหนึ่งช่องว่างที่มีผลต่อการเริ่มงานและร่างคำถามเพื่อยืนยัน

**Feedback:** คำถามทำให้ได้ข้อมูลที่เปลี่ยนการทำงานหรือไม่; สรุปตรงกับคำตอบที่ได้รับเพียงใด

**ลองต่างบริบท:** เปลี่ยนจากงานเอกสารเป็นคำขอบริการ ระบุว่าข้อจำกัดใดต่างและต้องถามอะไรใหม่

**หลักฐานถัดไป:** คำถามที่ผู้ใช้ถามจริง / ข้อความสรุปและสถานะการยืนยัน

**ขอบเขต AI:** AI ช่วยจัดโครงหรือชี้ข้อมูลที่ยังขาดได้ ผู้ใช้เป็นเจ้าของเหตุผลและปฏิเสธกิจกรรมได้; ไม่ grading

**หยุดเมื่อ:** ผู้ใช้ไม่ต้องการฝึก / งานเกินสิทธิหรือเสี่ยงกระทบคน/ระบบจริง / ต้องมีผู้รับผิดชอบเฉพาะทางแต่ยังไม่พร้อม
