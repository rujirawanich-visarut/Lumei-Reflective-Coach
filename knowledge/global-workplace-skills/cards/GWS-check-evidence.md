# ตรวจข้ออ้างและข้อมูลที่ขัดกัน

Check claims and conflicting evidence · `GWS-check-evidence` · release candidate 0.2.0 · runtime_authority: false

## ใช้เมื่อ

ข้อมูลหลายแหล่งไม่ตรงกัน หรือข้อสรุปยังมีหลักฐานไม่พอ

## พฤติกรรมและหลักฐาน

- **A1** ระบุข้ออ้างที่จะตรวจ และแยกข้อมูลที่พบจริงออกจากคำอธิบายหรือการคาดเดา (H-14)
- **A2** เปรียบเทียบแหล่งที่มา เวลา ขอบเขต และข้อมูลที่ยังขาดก่อนสรุปว่าข้อมูลขัดกัน (H-14)
- **A3** พิจารณาคำอธิบายอื่นและบันทึกว่ายังสรุปอะไรไม่ได้ รวมถึงสิ่งที่จะตรวจเพิ่ม (H-27)

หลักฐานที่มองหา: ข้ออ้างและข้อมูลที่อ้างถึง / บันทึกเทียบแหล่ง/ช่วงเวลา/นิยาม / ข้อจำกัดและคำอธิบายทางเลือก

## ขอบเขตและข้อจำกัด

- ใช้เฉพาะงานและข้อมูลที่ผู้ใช้มีสิทธิ
- ไม่แทนขั้นตอนองค์กรหรือความรู้เฉพาะวิชาชีพ
- เหตุการณ์คุกคาม ความปลอดภัยหรือความเสี่ยงสูงต้องใช้ช่องทางที่เหมาะสมก่อนกิจกรรมฝึก
- แหล่งที่มีอยู่มากกว่าไม่ได้แปลว่าเป็นจริงกว่า
- ความสัมพันธ์หรือแผนผังเหตุผลไม่พิสูจน์เหตุและผล
- ข้อเสนอการฝึกไม่ใช่หลักฐานว่าผู้ใช้เคยทำหรือทำได้แล้ว
- ไม่ให้คะแนน ระดับ proficiency หรือคำตัดสินตัวตนจากเหตุการณ์

## กิจกรรมฝึกที่เลือกได้

เลือกข้ออ้างหนึ่งข้อ ทำรายการข้อมูลที่สนับสนุนและข้อมูลที่ยังไม่รองรับ แล้วระบุการตรวจเพิ่มหนึ่งอย่าง

**Feedback:** ผู้อ่านตามกลับไปยังข้อมูลได้หรือไม่; มีการแยกข้ออ้าง ข้อมูล และสมมติฐานหรือไม่

**ลองต่างบริบท:** เปลี่ยนจากยอดรายงานเป็นข้อมูลสต็อก ระบุความต่างของนิยาม เวลา และวิธีตรวจ

**หลักฐานถัดไป:** ข้ออ้างและข้อมูลที่อ้างถึง / ข้อจำกัดและคำอธิบายทางเลือก

**ขอบเขต AI:** AI ช่วยจัดโครงหรือชี้ข้อมูลที่ยังขาดได้ ผู้ใช้เป็นเจ้าของเหตุผลและปฏิเสธกิจกรรมได้; ไม่ grading

**หยุดเมื่อ:** ผู้ใช้ไม่ต้องการฝึก / งานเกินสิทธิหรือเสี่ยงกระทบคน/ระบบจริง / ต้องมีผู้รับผิดชอบเฉพาะทางแต่ยังไม่พร้อม
