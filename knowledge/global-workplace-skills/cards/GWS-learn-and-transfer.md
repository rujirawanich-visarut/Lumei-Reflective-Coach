# เรียนรู้จาก feedback และนำบทเรียนไปใช้

Learn from feedback and transfer · `GWS-learn-and-transfer` · release candidate 0.2.0 · runtime_authority: false

## ใช้เมื่อ

มี feedback ความผิดพลาด หรือการลองครั้งหนึ่งที่อยากนำไปปรับครั้งถัดไป

## พฤติกรรมและหลักฐาน

- **A1** ระบุสิ่งที่ทำ ผลที่รายงานและ feedback ที่มี โดยไม่สรุปตัวตนจากความผิดพลาด (H-12)
- **A2** เลือกสิ่งที่จะปรับหนึ่งอย่างและลองการกระทำนั้นด้วยตนเองเมื่อเหมาะสม (H-06, H-12)
- **A3** เปรียบเทียบสิ่งที่เกิดกับความตั้งใจ แล้วระบุว่าจะปรับบทเรียนอย่างไรในบริบทอื่น (H-06, H-12)

หลักฐานที่มองหา: เหตุการณ์/feedback ที่ระบุแหล่งได้ / การลองครั้งถัดไปที่ผู้ใช้ลงมือ / ความเหมือน/ต่างของบริบทและผลที่สังเกตได้

## ขอบเขตและข้อจำกัด

- ใช้เฉพาะงานและข้อมูลที่ผู้ใช้มีสิทธิ
- ไม่แทนขั้นตอนองค์กรหรือความรู้เฉพาะวิชาชีพ
- เหตุการณ์คุกคาม ความปลอดภัยหรือความเสี่ยงสูงต้องใช้ช่องทางที่เหมาะสมก่อนกิจกรรมฝึก
- สะท้อนคิดได้ไม่เท่ากับใช้ทักษะได้แล้ว
- การลองหนึ่งครั้งไม่พิสูจน์ transfer หรือประสิทธิผลถาวร
- ข้อเสนอการฝึกไม่ใช่หลักฐานว่าผู้ใช้เคยทำหรือทำได้แล้ว
- ไม่ให้คะแนน ระดับ proficiency หรือคำตัดสินตัวตนจากเหตุการณ์

## กิจกรรมฝึกที่เลือกได้

เลือก feedback หนึ่งข้อ ร่างและลองการปรับหนึ่งอย่าง แล้วจดสิ่งที่เห็นโดยไม่ให้คะแนนตนเอง

**Feedback:** มีการเปลี่ยนการกระทำจริงหรือไม่; แยก feedback ที่ได้รับจากคำอธิบายที่สร้างภายหลังหรือไม่

**ลองต่างบริบท:** เลือกสถานการณ์ใหม่ที่ผู้รับงานหรือข้อจำกัดต่าง แล้วระบุว่าใช้ส่วนใดของบทเรียนและต้องปรับส่วนใด

**หลักฐานถัดไป:** เหตุการณ์/feedback ที่ระบุแหล่งได้ / ความเหมือน/ต่างของบริบทและผลที่สังเกตได้

**ขอบเขต AI:** AI ช่วยจัดโครงหรือชี้ข้อมูลที่ยังขาดได้ ผู้ใช้เป็นเจ้าของเหตุผลและปฏิเสธกิจกรรมได้; ไม่ grading

**หยุดเมื่อ:** ผู้ใช้ไม่ต้องการฝึก / งานเกินสิทธิหรือเสี่ยงกระทบคน/ระบบจริง / ต้องมีผู้รับผิดชอบเฉพาะทางแต่ยังไม่พร้อม
