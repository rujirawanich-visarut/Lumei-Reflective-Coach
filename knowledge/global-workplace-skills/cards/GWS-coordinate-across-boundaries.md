# ประสานงานและสร้างความร่วมมือข้ามขอบเขต

Coordinate across boundaries · `GWS-coordinate-across-boundaries` · release candidate 0.2.0 · runtime_authority: false

## ใช้เมื่อ

งานต้องอาศัยคนต่างทีมที่ผู้ใช้ไม่มีอำนาจสั่งการ

## พฤติกรรมและหลักฐาน

- **A1** ระบุผลร่วมและการพึ่งพากัน รวมทั้งข้อจำกัดของฝ่ายที่เกี่ยวข้อง (H-09, H-32)
- **A2** อธิบายข้อเสนอด้วยเหตุผลที่เกี่ยวกับความต้องการของอีกฝ่าย และเชิญให้เสนอทางเลือก (H-04)
- **A3** ขอข้อตกลงที่ทำได้จริง ระบุจุดส่งต่อและติดตามโดยไม่ถือว่าคำขอคือคำสั่ง (H-32, H-11)

หลักฐานที่มองหา: ผู้เกี่ยวข้องและ dependency ที่พบจริง / ข้อเสนอ/ทางเลือกที่แลกเปลี่ยน / คำยืนยันของแต่ละฝ่ายและจุดติดตาม

## ขอบเขตและข้อจำกัด

- ใช้เฉพาะงานและข้อมูลที่ผู้ใช้มีสิทธิ
- ไม่แทนขั้นตอนองค์กรหรือความรู้เฉพาะวิชาชีพ
- เหตุการณ์คุกคาม ความปลอดภัยหรือความเสี่ยงสูงต้องใช้ช่องทางที่เหมาะสมก่อนกิจกรรมฝึก
- ไม่มีคำตอบยังไม่ถือว่าได้รับความร่วมมือ
- ความร่วมมือไม่อนุญาตให้ใช้ข้อมูลหรือทรัพยากรที่ยังไม่ได้รับสิทธิ
- ข้อเสนอการฝึกไม่ใช่หลักฐานว่าผู้ใช้เคยทำหรือทำได้แล้ว
- ไม่ให้คะแนน ระดับ proficiency หรือคำตัดสินตัวตนจากเหตุการณ์

## กิจกรรมฝึกที่เลือกได้

เขียนคำขอความร่วมมือที่ระบุผลร่วม สิ่งที่ต้องการ และทางเลือกให้คู่ร่วมงานต่อรองได้

**Feedback:** ผู้รับรู้ว่าคำขอช่วยงานของเขาอย่างไรหรือไม่; เขามีสิทธิตอบรับ ต่อรอง หรือปฏิเสธหรือไม่

**ลองต่างบริบท:** เปลี่ยนจากประสานทีมข้อมูลเป็นประสานคนต่างกะ ระบุ dependency และช่องทางที่ต่าง

**หลักฐานถัดไป:** ผู้เกี่ยวข้องและ dependency ที่พบจริง / คำยืนยันของแต่ละฝ่ายและจุดติดตาม

**ขอบเขต AI:** AI ช่วยจัดโครงหรือชี้ข้อมูลที่ยังขาดได้ ผู้ใช้เป็นเจ้าของเหตุผลและปฏิเสธกิจกรรมได้; ไม่ grading

**หยุดเมื่อ:** ผู้ใช้ไม่ต้องการฝึก / งานเกินสิทธิหรือเสี่ยงกระทบคน/ระบบจริง / ต้องมีผู้รับผิดชอบเฉพาะทางแต่ยังไม่พร้อม

## ความต่างจาก card ใกล้เคียง
