# สื่อสารให้คนต่างพื้นหลังมีส่วนร่วม

Communicate across backgrounds · `GWS-communicate-across-backgrounds` · release candidate 0.2.0 · runtime_authority: false

## ใช้เมื่อ

คนเกี่ยวข้องมีภาษา ประสบการณ์ ช่องทางหรือข้อจำกัดการเข้าถึงต่างกันและต้องเข้าใจเรื่องเดียวกัน

## พฤติกรรมและหลักฐาน

- **A1** ถามความต้องการด้านภาษา ช่องทางและข้อมูลจากผู้เกี่ยวข้องโดยไม่เดาจากกลุ่มหรือตำแหน่ง (H-34, H-11)
- **A2** ปรับถ้อยคำ รูปแบบหรือช่องทางให้เหมาะกับความต้องการที่ได้รับ และเปิดให้ผู้เกี่ยวข้องเสนอความเห็น (H-11, H-34)
- **A3** ตรวจความเข้าใจด้วยการสรุปสิ่งที่ตกลงและปรับเมื่อพบว่าข้อความยังไม่ชัด (H-11)

หลักฐานที่มองหา: ความต้องการที่ผู้รับบอก / ข้อความหรือรูปแบบก่อนและหลังปรับ / คำยืนยันหรือความเข้าใจที่ยังไม่ตรงกัน

## ขอบเขตและข้อจำกัด

- ใช้เฉพาะงานและข้อมูลที่ผู้ใช้มีสิทธิ
- ไม่แทนขั้นตอนองค์กรหรือความรู้เฉพาะวิชาชีพ
- เหตุการณ์คุกคาม ความปลอดภัยหรือความเสี่ยงสูงต้องใช้ช่องทางที่เหมาะสมก่อนกิจกรรมฝึก
- ไม่อนุมานวัฒนธรรม ความสามารถหรือความต้องการจากสัญชาติ/อายุ
- ไม่รับรอง accessibility compliance จากข้อความเดียว
- ข้อเสนอฝึกไม่ใช่การกระทำที่เกิดแล้ว; ไม่ให้คะแนนหรือระดับบุคคล

## กิจกรรมฝึกที่เลือกได้

ลองอธิบายงานเดียวกันแก่ผู้รับสมมติสองคนที่ระบุช่องทางและประสบการณ์ต่างกัน โดยให้ข้อมูลหลักครบเท่ากัน

**Feedback:** เปลี่ยนวิธีอธิบายตามความต้องการที่ระบุโดยไม่ลดข้อมูลสำคัญหรือใช้ stereotype หรือไม่

**ลองต่างบริบท:** เปลี่ยนจากอีเมลฝ่ายสำนักงานเป็นข้อความส่งกะ ระบุช่องทางและข้อจำกัดที่ต้องถามใหม่

**หลักฐานถัดไป:** ความต้องการที่ผู้รับบอก / คำยืนยันหรือความเข้าใจที่ยังไม่ตรงกัน

**ขอบเขต AI:** AI ช่วยจัดโครงหรือชี้ข้อมูลที่ยังขาดได้ ผู้ใช้เป็นเจ้าของเหตุผลและปฏิเสธกิจกรรมได้; ไม่ grading

**หยุดเมื่อ:** ผู้ใช้ไม่ต้องการฝึก / งานเกินสิทธิหรือเสี่ยงกระทบคน/ระบบจริง / ต้องมีผู้รับผิดชอบเฉพาะทางแต่ยังไม่พร้อม
