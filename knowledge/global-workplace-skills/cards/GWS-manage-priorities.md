# จัดลำดับงานและปรับข้อตกลง

## ใช้เมื่อ

งานหลายชิ้นแย่งเวลา หรือภาระงานเกินทรัพยากรที่มี

## พฤติกรรมและหลักฐาน

- **A1** ทำให้งาน กำหนดส่ง dependency และทรัพยากรที่มีเห็นได้ชัด (H-26)
- **A2** เลือกสิ่งที่ทำก่อนตามความสำคัญ ผลกระทบและข้อจำกัด พร้อมบอกสิ่งที่จะเลื่อน (H-26, H-33)
- **A3** แจ้ง tradeoff และขอปรับข้อตกลงกับผู้เกี่ยวข้องเมื่อแผนเดิมทำไม่ได้ (H-11, H-26)

หลักฐานที่มองหา: รายการงานและกำหนดส่งที่ใช้วางแผน / เหตุผลการจัดลำดับและสิ่งที่เลื่อน / การสื่อสาร/คำตอบเรื่องข้อตกลงใหม่

## ขอบเขตและข้อจำกัด

- ใช้เฉพาะงานและข้อมูลที่ผู้ใช้มีสิทธิ
- ไม่แทนขั้นตอนองค์กรหรือความรู้เฉพาะวิชาชีพ
- เหตุการณ์คุกคาม ความปลอดภัยหรือความเสี่ยงสูงต้องใช้ช่องทางที่เหมาะสมก่อนกิจกรรมฝึก
- งานเสร็จน้อยไม่พิสูจน์ว่าจัดเวลาไม่ดี
- คำขอเลื่อนยังไม่ใช่กำหนดส่งใหม่ที่ตกลงแล้ว
- ข้อเสนอการฝึกไม่ใช่หลักฐานว่าผู้ใช้เคยทำหรือทำได้แล้ว
- ไม่ให้คะแนน ระดับ proficiency หรือคำตัดสินตัวตนจากเหตุการณ์

## กิจกรรมฝึกที่เลือกได้

เลือกงานสามชิ้นจากเหตุการณ์จริง ระบุสิ่งที่จะทำก่อนหนึ่งชิ้นและร่างคำขอปรับข้อตกลงหนึ่งเรื่อง

**Feedback:** ลำดับสัมพันธ์กับผลกระทบและทรัพยากรจริงหรือไม่; ระบุสิ่งที่หยุด/เลื่อนอย่างโปร่งใสหรือไม่

**ลองต่างบริบท:** เปลี่ยนจากแผนรายสัปดาห์เป็นงานเร่งช่วงเปลี่ยนกะ ระบุข้อมูลและอำนาจที่ต้องยืนยันใหม่

**หลักฐานถัดไป:** รายการงานและกำหนดส่งที่ใช้วางแผน / การสื่อสาร/คำตอบเรื่องข้อตกลงใหม่

**ขอบเขต AI:** AI ช่วยจัดโครงหรือชี้ข้อมูลที่ยังขาดได้ ผู้ใช้เป็นเจ้าของเหตุผลและปฏิเสธกิจกรรมได้; ไม่ grading

**หยุดเมื่อ:** ผู้ใช้ไม่ต้องการฝึก / งานเกินสิทธิหรือเสี่ยงกระทบคน/ระบบจริง / ต้องมีผู้รับผิดชอบเฉพาะทางแต่ยังไม่พร้อม
