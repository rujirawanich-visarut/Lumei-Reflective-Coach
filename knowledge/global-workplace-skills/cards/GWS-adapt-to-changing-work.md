# ปรับวิธีทำงานเมื่อเงื่อนไขเปลี่ยน

Adapt to changing work · `GWS-adapt-to-changing-work` · release candidate 0.2.0 · runtime_authority: false

## ใช้เมื่อ

ข้อกำหนด เครื่องมือหรือวิธีทำงานเปลี่ยนและแผนเดิมอาจใช้ต่อไม่ได้

## พฤติกรรมและหลักฐาน

- **A1** ตรวจว่าข้อกำหนดหรือบริบทใดเปลี่ยนและข้อมูลใดยังต้องยืนยันก่อนปรับงาน (H-17)
- **A2** ปรับการกระทำหนึ่งอย่างให้สอดคล้องกับเงื่อนไขใหม่ภายในสิทธิ และแจ้งผลต่อข้อตกลงเดิม (H-17, H-11)
- **A3** ทบทวนข้อมูลจากการลองและเปลี่ยนวิธีอีกเมื่อพบว่าวิธีเดิมไม่ตอบเงื่อนไขใหม่ (H-17)

หลักฐานที่มองหา: ข้อกำหนดก่อนและหลังเปลี่ยน / การปรับที่ผู้ใช้ทำจริงและขอบเขตสิทธิ / ข้อมูลตรวจหลังปรับหรือเหตุผลที่ยังรอ

## ขอบเขตและข้อจำกัด

- ใช้เฉพาะงานและข้อมูลที่ผู้ใช้มีสิทธิ
- ไม่แทนขั้นตอนองค์กรหรือความรู้เฉพาะวิชาชีพ
- เหตุการณ์คุกคาม ความปลอดภัยหรือความเสี่ยงสูงต้องใช้ช่องทางที่เหมาะสมก่อนกิจกรรมฝึก
- ไม่บังคับให้มองทุกการเปลี่ยนในแง่ดี
- การลองหนึ่งครั้งไม่พิสูจน์ adaptability เป็นคุณลักษณะถาวร
- การเปลี่ยนขั้นตอนสำคัญต้องผ่านผู้มีอำนาจก่อน
- ข้อเสนอฝึกไม่ใช่การกระทำที่เกิดแล้ว; ไม่ให้คะแนนหรือระดับบุคคล

## กิจกรรมฝึกที่เลือกได้

เลือกงานสมมติหนึ่งชิ้นที่ข้อกำหนดเปลี่ยน ระบุสิ่งที่ต้องคงไว้และลองแก้วิธีหนึ่งอย่างในขอบเขตที่อนุญาต

**Feedback:** วิธีใหม่ตอบเงื่อนไขที่เปลี่ยนหรือไม่ และยังรักษาข้อจำกัดที่จำเป็นหรือไม่

**ลองต่างบริบท:** เปลี่ยนจากแบบฟอร์มใหม่เป็นเวลาส่งมอบใหม่ อธิบายว่าอะไรปรับเองได้และอะไรต้องขออนุมัติ

**หลักฐานถัดไป:** ข้อกำหนดก่อนและหลังเปลี่ยน / ข้อมูลตรวจหลังปรับหรือเหตุผลที่ยังรอ

**ขอบเขต AI:** AI ช่วยจัดโครงหรือชี้ข้อมูลที่ยังขาดได้ ผู้ใช้เป็นเจ้าของเหตุผลและปฏิเสธกิจกรรมได้; ไม่ grading

**หยุดเมื่อ:** ผู้ใช้ไม่ต้องการฝึก / งานเกินสิทธิหรือเสี่ยงกระทบคน/ระบบจริง / ต้องมีผู้รับผิดชอบเฉพาะทางแต่ยังไม่พร้อม
